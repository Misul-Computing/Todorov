# local 100k source native relation adapter

status: historical context only. frozen as of 2026-05-13. do not edit.

## summary

`local_100k_source_native_relation_adapter` is a demoted source-relation diagnostic after the semantic-alias failure.

it stores a transformed compressed source block inside torch module state, parses source-native evidence terms, and uses a charged one-byte relation constant to answer from a later source span.

the implementation passes its mechanical checks but is not promoted. the relation is fixed offset arithmetic, and a fair stride-aware content scan with the same parser and relation rule retrieves every answer exactly.

## category check

implemented operation: a charged fixed-stride relation codec over a transformed compressed source block.

strongest baseline: stride-aware same-interface content scan, which reaches `1.0` exact success.

what passed: the compressed payload remains inside model state, exact and paraphrase answers pass, disabled controls collapse, source train/test overlap checks are zero, and the relationless scan fails.

what failed or remains unproved: the target value is generated by a fixed source offset rule, the one-byte relation constant is not learned semantic routing, and the fair stride-aware scanner solves the same task exactly.

why not promoted to breakthrough: the task is still formula-generated. the candidate does not beat a fair scanner that receives the same parser and relation rule.

## decision

accepted only as a diagnostic. the next attempt must use authored source-native relations already present in the corpus, such as wiki links or import edges, and must include a matched relation-aware scanner before any promotion.
