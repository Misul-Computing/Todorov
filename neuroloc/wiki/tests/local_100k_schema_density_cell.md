## what was done

the simulation builds a bounded schema-generative associative cell. it fits compact modular schema coefficients from held-out training examples, commits those coefficients as the active cell state, and answers exact key queries over a much larger held-out structured fact set.

the cell has no per-fact runtime dictionaries for values, provenance, or commit rows. value and provenance are recovered from the fitted schema path. an independent random-label control uses the same key surface and fitting route but fails held-out exact retrieval, which blocks any claim that independent entropy was compressed.

## category check

implemented operation: exact associative read over a structured schema-generated fact family, with compact fitted coefficients as committed state.

strongest baseline: verbatim table, product-key-style lookup, content-routed sparse read, mini titans/miras-style bounded test-time memory, scalar mlp capacity, no-memory, recency-only, shuffled-key, shuffled-value, shuffled-provenance, schema-disabled, shuffled-schema, write-disabled, read-disabled, decoder-disabled, and independent random-label controls.

what passed: strict state-charged density clears the 600x target for the structured schema family, exact retrieval is 1.0, controls collapse, and no per-fact runtime rows are committed.

what failed: the target itself is invalid for the requested knowledge-compression claim because the facts are generated by planned structure. see [[mistakes/schema_density_cell_structured_target_category_error]].

what is not proved: strict 600x compression of unstructured or unknown-structure knowledge, independent random facts, biological neuron-density storage, unsupervised world-code discovery, broad neural-model competence, arbitrary chat, paid-scale trainability, or external simulator transfer.

why this cannot be accepted as the requested result: the useful bits are generated by a compact schema chosen by the simulation. the random entropy control shows the same path cannot compress independent labels. the result is formula compression, not the high-density knowledge cell deyan requested.

## verdict

demoted. it remains useful only as a boundary artifact showing that structured formula families are not the target. it does not supersede [[tests/local_100k_high_density_cell]], and the previous independent-fact strict failure remains valid.
